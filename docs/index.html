What is CloudBridge?

CloudBridge is an Android file-management app built around rclone. Provider setup and compatibility vary by app configuration and the fork-pinned engine. Source paths exist for file management, transfers, streaming and schedules, but this list is not a claim that every provider or lifecycle passed acceptance testing.

CloudBridge is free and open source software (GPLv3). It is a fork of RCX, which is itself a fork of rcloneExplorer.

Bisync preview only: safe initialization, apply, and recovery are not available in this fork. Do not use it for two-way Bisync mutations or treat a preview as authorization to change either endpoint.

Highlights

  • File management — list, view, download, upload, move, rename, delete.
  • Streaming - source paths exist for serving protocols; security and lifecycle acceptance remains incomplete.
  • Sync tasks - task and schedule paths exist; timing and background lifecycle are not guaranteed or device-accepted.
  • Encryption - rclone crypt can encrypt configured content before upload; settings and recovery keys must be handled carefully.
  • Local storage — Storage Access Framework (SAF) support for SD cards and USB devices.
  • rclone integration - the configured source fork and immutable commit are recorded in build properties; native APK integration is not verified.
  • Material 3 design — including dark theme.
  • Multiple architectures — ARM, ARM64, x86 and x64; Android 6+ (minSdk 23).
