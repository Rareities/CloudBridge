Privacy review status for the Rareities fork

Important: this page is an interim transparency notice, not a complete or legally reviewed privacy policy for the Rareities fork. A source and data-flow audit is still required. The fork has no published release as of 2026-09-25. Do not rely on inherited upstream statements about collection, sharing, updates, Play distribution, or user rights as verified Rareities policy.

The current source includes Android app code and the rclone engine for file and remote operations. This repository has not completed the audit needed to make a comprehensive claim about every data flow, dependency, updater request, operating system backup, or third-party service. Do not interpret this page as a guarantee that no information is transmitted or processed outside the device.

1. Who is responsible

This is a community fork maintained under the Rareities/CloudBridge repository. A fork-specific legal data controller and private reporting contact have not been confirmed. The inherited upstream maintainer and contact details do not represent confirmed Rareities support or privacy contacts. The fork issue tracker is disabled.

2. Data stored and processed on your device

The source contains local app data and configured remote credentials. The exact storage, backup, and transmission behavior has not yet been independently audited end to end. In particular:

  • Remote credentials and OAuth tokens may be stored in the rclone configuration in app-private storage. The app does not encrypt the whole config file at rest; rclone per-value obscuring is reversible.
  • App settings (theme, preferences, task definitions).
  • Files you download or upload with CloudBridge, in the locations you choose.
  • Crypt passwords and other remote settings may be present in configuration. Treat them as sensitive.

When CloudBridge stores the rclone config passphrase, the source wraps that passphrase with Android Keystore AES-GCM. This does not encrypt the entire configuration file. Device-specific Keystore behavior and operating-system backup handling still require verification. Clearing app data may remove local configuration and credentials; it does not delete remote files.

3. Network activity and third-party services (incomplete audit)

When you request remote operations, the app and rclone may exchange data with configured providers and related authentication endpoints. Exact destinations and metadata depend on the selected backend and configuration. A complete network capture/source review has not been completed, so this page does not claim that provider traffic is the only network activity or that no third party can access data.

4. Update check

When update notifications are enabled, source code schedules a connected-network WorkManager check on a 14-day interval; Android may run periodic work later than requested. The worker requests the GitHub releases API for Rareities/CloudBridge (up to five pages of 100 published releases) and notifications open that fork's latest-release page. If all five pages are full, the worker leaves the stored update state unchanged. It does not download or install an update. The preference defaults off in the inspected source; there is no verified Rareities release candidate as of 2026-09-25. Runtime request behavior and device scheduling have not been tested here. Do not infer that the API request carries no network metadata.
