Privacy Policy for ProtonBridge

Last updated: October 12, 2026

ProtonBridge is a cloud file manager for Android. This policy explains what data the app processes and where that data goes. The short version: ProtonBridge has no app analytics or advertising SDK. The app contains no analytics, no advertising and no crash-reporting SDKs. All your files and login credentials stay on your device and go directly to the cloud providers you configure — never to the developer.

1. Who is responsible

ProtonBridge is a personal open-source fork maintained by Rareities, descended from CloudBridge, Round Sync, RCX and rcloneExplorer. Contact the maintainer through ProtonBridge issues or via the GitHub project.

2. Data stored and processed on your device

The following data is created and stored locally on your device only:

  • Cloud account credentials and OAuth tokens for the remotes you configure. These are stored in a native encrypted rclone configuration in private storage; the password is wrapped using Android Keystore. Background sync uses unattended access. A compromised running app or device can defeat these protections. They are used solely to access your accounts on your instruction.
  • App settings (theme, preferences, task definitions).
  • Files you download or upload with ProtonBridge, in the locations you choose.
  • Crypt passwords you configure for encrypted remotes. These are used locally to encrypt/decrypt crypt-remote content. Exported configurations or backups may contain secrets; protect them and their passphrases.

You can delete all of this at any time by removing the remotes/tasks in the app, clearing the app's storage, or uninstalling the app.

3. Data transferred to third parties (only on your instruction)

When you browse, upload, download or sync files, ProtonBridge connects directly from your device to the cloud providers you configured (for example Google Drive, OneDrive, Dropbox, Nextcloud, Internxt, or any rclone-compatible provider). Those transfers use each provider's own protocols and are subject to the respective provider's privacy policy. The developer has no access to this data and operates no server that your files pass through.

4. Update check

If you enable update notifications, the app periodically asks the GitHub API whether a newer release of ProtonBridge exists. The app does not deliberately add account credentials, file paths or usage statistics to these requests. GitHub receives ordinary network metadata such as your IP address and request headers. When an update is found, the app shows a notification with a link to the release page; it does not download or install anything by itself.

5. Permissions and why the app needs them

6. Distribution and exports

This fork is distributed through GitHub releases, independently from upstream store apps. Exported backups, logs and previews can contain secrets or filenames; sharing them is your choice. Android automatic backup is disabled. Delete local exports separately if you no longer need them.

7. Your rights (GDPR)

Because the developer does not collect or process any personal data, there is no personal data held by the developer that could be accessed, corrected or deleted. Data on your device is under your full control at all times. If you have any privacy concern or question about this policy, contact the developer at the address above.

8. Children

ProtonBridge is a general-purpose file tool and is not directed at children under 13.

9. Changes to this policy

If this policy changes, the updated version will be published on this page with a new "last updated" date, and it will be linked from the app's repository.

10. Open source

You do not have to take these statements on faith: ProtonBridge is fully open source, and you can inspect every line of code in the public repository.
