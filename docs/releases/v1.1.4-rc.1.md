# ProtonBridge 1.1.4-rc.1 — simpler flags and complete reference

Updates the existing ProtonBridge package with the same signing certificate;
base versionCode 140. The reviewed rclone engine pin is unchanged.

- Type one custom flag per line: `--flag`, `--flag value` or `--flag=value`.
  String values, spaces and Unicode are supported; quotes are not required.
  Each line becomes one argument, without invoking a shell.
- `--conflict-resolve newer` now works: modtime comparison is added alongside
  mandatory size/checksum checks. The engine's other resolution modes are also
  supported, and numbered conflict copies preserve losing content.
- Removed Build a flag, performance presets and View rclone command. Existing
  saved flags and transfer counts are preserved.
- The remaining rclone flag reference lists bisync and all global/backend flags,
  with explanations/defaults from the exact bundled engine and searchable complete
  entries. It is a local reference, not a sync or account connection. Some engine
  options belong in app controls/remote configuration and remain protected.

After changing flags, save and review a fresh preview before initialisation.
Task approval fingerprints include the conflict policy. Modification-time-based
resolution requires both endpoints to support modification times; rclone warns
and falls back to preserving conflicts when an endpoint cannot support it.

Parser/argument tests and a real 20-file local native bisync fixture verify newer
wins on both sides and older content survives in conflict copies with checksums
and safety checks enabled. No live-account or device acceptance test was run.
