# Release candidate validation

This record supplements the complete changelog and the 45-package master-plan
coverage register. It records controlled results, not universal compatibility.

## Final source changes

The last review corrected raw authentication-response logging, unbounded or
incompletely cancelled setup processes, duplicate remote-edit submission,
blocking remote saves, and unsafe remote-form recreation. Credentials are not
serialised into fragment arguments or the dynamic form's saved hierarchy.

A physical GUI test exposed a lost preview tap. The regression dispatches real
touch down/up events, refreshes state before Android delivers the queued click,
and checks for the preview dialog. It fails before the correction and passes
afterwards: refresh applies each action's final availability once, avoiding a
temporary disable that cancels the queued click.

## Executed checks

- 162 host tests across 44 suites: zero failures, errors or skipped tests. The
  native encryption test used the independently verified published Windows CLI.
- Root lint passed with the existing baseline unchanged: 196 visible app
  warnings; two errors and 428 warnings remain filtered by that baseline.
- 13 API 35 x86_64 emulator cases passed across 11 explicit phases. Coverage
  includes complete native and GUI bisync, real remote setup/edit/recreation,
  all six ordinary task modes, provider transfers/mutations, RC idle/restart,
  actual WorkManager charging/cancellation, missed-run reconciliation and
  encrypted restore rollback across process restart.
- Four architecture APKs plus universal builds were verified for source pin,
  native hashes, Android PIE, 16 KiB ELF load alignment and signing identity.
  Release packages additionally require non-debuggable installation metadata.
- The actual minified, signed, non-debuggable release APK passed its separate
  runtime case: protected configuration, native preview, explicit initialisation,
  two-way synchronisation and task-editor launch. The fixture waits for confirmed
  WorkManager completion between operations without changing production keep rules.
- Engine regression, concurrent credential saves, negative crypto, strict
  listing/identity and subprocess acceptance passed in its release CI. Its
  published source is `47048daf3c80e1de633ec9a1f09981f4c30f9a30`.
- A fresh Go 1.27.2 source-level vulnerability scan found no called vulnerable
  symbols and no imported vulnerable packages. One advisory applies to an
  unimported legacy package in a required module; this is not a claim that every
  dependency is free of advisories. The maintained Proton crypto package is used.

The initially proposed follow-up SSH update was rejected: GO-2026-5319 concerns
Incus and the proposed dependency version does not exist. No speculative engine
release or dependency change was introduced. The matching engine release remains
`v1.76.0-cloudbridge.1`.

## Reproduction

Use JDK 17, Go 1.27.2 and the pinned Android SDK/NDK. Set
`CLOUDBRIDGE_TEST_RCLONE` to a verified host CLI, then run:

```text
./gradlew testOssDebugUnitTest lint assembleOssDebug assembleOssDebugAndroidTest
```

Run `scripts/Verify-Emulator.ps1` only against an explicitly disposable API 35
emulator, with the matching app and instrumentation APK. The signed production
package has a separate `ReleasePackageDeviceTest` acceptance mode; see the
instrumentation source. Final GitHub run IDs and downloaded asset hashes are in
the release and delivery manifest rather than embedded as a moving source SHA.

## External acceptance gates

No personal Proton credentials were used. Live disposable-account cross-client
interoperability, long-lived refresh/revocation, account and crypto-migration
matrices, physical devices, OS quota exhaustion and controlled battery/thermal
measurements remain unverified. The emulator is not evidence of physical energy
savings or all API/ABI/16 KiB-page hardware behaviour. Photos, Shared With Me,
instant events, desktop and per-run biometric unlock remain deferred as stated
in the master-plan register. The published artifacts are release candidates.
