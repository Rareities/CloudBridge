## WP12 exit rule

Do not mark a feature “preserved” solely because a class, README bullet, or old changelog exists. For each feature, record the owning layer, regression test(s), supported provider/Android version, actual result, and known exclusions in the execution ledger. Unavailable Galaxy/Proton access is **NOT RUN**, not passed. Preserve all listed feature paths unless the master handoff explicitly authorizes a removal after review.
