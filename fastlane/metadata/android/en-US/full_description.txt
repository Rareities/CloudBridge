CloudBridge is a cloud file manager for Android, powered by a pinned Rareities/rclone fork. It helps you manage files on local storage and configured remote backends supported by the included engine. Provider and Android permission capabilities vary.

* <b>File Management:</b> List, view, download, upload, move, rename and delete files and folders where the selected provider and Android permissions support those operations
* <b>Streaming:</b> Stream media files, serve files and directories over FTP, HTTP, WebDAV or DLNA
* <b>Syncing:</b> Create tasks and schedules for file synchronization; Android may delay background work
* <b>Encryption:</b> Use rclone crypt remotes to encrypt file contents before transfer, with behavior determined by the configured crypt options
* <b>Remote backends:</b> Configure backends supported by the included engine, including Internxt and Drime; provider features vary
* <b>Material Design:</b> Supports automatic dark theme in the style of Material 3
* <b>Removable storage:</b> Uses Android's Storage Access Framework for supported SD-card and USB routes, subject to device/provider permissions

This Rareities fork is based on the original CloudBridge project and is distributed under GPLv3. Original authors and contributors are credited in the app. Source and fork release information: https://github.com/Rareities/CloudBridge. The fork's issue tracker and private security-reporting route were not available in the latest repository review; do not send sensitive information through public channels.
